# Moon Core

**Переделай интерфейс VS Code под себя: кликни по элементу — убери, увеличь, перекрась.**

Конструктор интерфейса, готовые профили и стили, живые CSS/JS-сниппеты —
с отменой каждой правки и безопасным режимом. Код писать не обязательно.

</div>

---

## Что это

Moon Core встраивает свой рантайм в оболочку VS Code и поэтому умеет то, чего нет в API
расширений: менять любой элемент окна. При этом ничего не теряется: всё, что изменено,
лежит списком во вкладке «Правки» и возвращается одним щелчком.

- **Конструктор** — окно VS Code как редактируемый макет: навёл, кликнул, поменял.
- **Профили вида** — «Минимал», «Только код», «Крупный», «Дзен», «Презентация», «Компактный»
  и свои; включаются сами по языку, ветке, проекту, теме или времени суток.
- **Галерея стилей** — готовые стили галочками, без кода.
- **Сниппеты** — свои `.css` и `.js` с живым предпросмотром на каждый символ.

## Возможности

- **Любой элемент окна**: скрыть, прозрачность, фон, рамка, тень, скругление, масштаб,
  отступы, шрифт, цвет; ручки прямо на рамке элемента.
- **Настройки VS Code первыми**: если для элемента есть штатная настройка, конструктор
  предлагает её — это переживает обновления.
- **Цвета темы мышкой**: какой цвет темы красит элемент — и его замена через
  `workbench.colorCustomizations`.
- **Свои кнопки**: любая команда VS Code кнопкой в статусбаре, титлбаре или над редактором.
- **Пипетка** `Ctrl+Alt+Shift+C`: селектор элемента под курсором, «Скрыть», «Стиль в CSS».
- **Модули**: другие расширения встраивают своё окно через Moon Core, без своего патча оболочки.
- **Доктор**: всё состояние на одной странице и кнопка починки у каждой проблемы.
- **Скорость VS Code**: сколько стоит каждое расширение на старте, этапы запуска окна, подвисания,
  тяжёлые папки проекта и советы по настройкам с кнопкой «Вернуть как было».

## Быстрый старт

1. Установи расширение и перезапусти VS Code.
2. Moon Core сам встроится в оболочку и предложит перезагрузить окно.
3. Открой панель **Moon Core** в панели действий слева или выполни команду
   **«Moon Core: Конструктор интерфейса»**.

## Если что-то пошло не так

| Что | Как |
|---|---|
| Правка спрятала нужное | `Ctrl+Alt+Shift+Backspace` — стоп-кран: все стили Moon Core выключены в этом окне |
| Вернуть шаг назад | `Ctrl+Z` в конструкторе или «Moon Core: Отменить последнюю правку конструктора» |
| Вернуть прежний вид | «Moon Core: Восстановить вид из резервной копии» |
| Проверить, виноват ли Moon Core | «Moon Core: Безопасный режим» (`Ctrl+Alt+Shift+F12`) |
| VS Code не открывается | `moon-core-restore.cmd` в папке данных расширения |

> Moon Core правит файлы самого VS Code. Хэш оболочки пересчитывается, поэтому баннера
> «установка повреждена» нет; «Moon Core: Убрать из VS Code» и удаление расширения возвращают
> оболочку байт в байт. После обновления VS Code Moon Core встраивается заново сам.

## Настройки

| Настройка | Назначение |
|---|---|
| `moonCore.livePreview` | Живой предпросмотр несохранённого CSS. |
| `moonCore.autoProfiles` | Профили по контексту: язык, папка, ветка, тема, время суток. |
| `moonCore.autoReinject` | Встраиваться заново после обновления VS Code без вопроса. |
| `moonCore.sync` | Синхронизировать вид через Settings Sync. |
