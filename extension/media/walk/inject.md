# Встраивание

Moon Core дописывает свой блок в оболочку VS Code (`workbench.html`) — так он может менять сам интерфейс, а не только тему.

- Перед записью делается копия оболочки, а результат проверяется: кроме блока Moon Core ничего не меняется.
- После обновления VS Code блок возвращается сам.
- «Moon Core: Убрать из VS Code» возвращает оболочку байт в байт.
- Если VS Code не открывается, в папке данных расширения лежит `moon-core-restore.cmd`.
