# Конструктор

Кликни по элементу — справа появится панель.

- **Быстро**: скрыть, крупнее, мельче, прозрачнее.
- **Ручки на рамке**: тяни — меняются размер и масштаб.
- **Карта**: всё, что есть в окне, списком с поиском.
- **Ещё**: акцентный цвет, шрифт интерфейса, скругление, эффекты, свои кнопки.

Клавиши: стрелка вверх — родитель, Delete — скрыть, Ctrl+Z — отменить, Esc — выйти. Alt+клик работает как обычный клик.
