## Внедрение в оболочку

1. **[сделано]** Запись плана «всё или ничего»: упала запись посреди плана — уже записанное откатывается.
2. **[сделано]** Атомарная запись с повторами rename при EBUSY/EPERM (файл читает другое окно или антивирус).
3. **[сделано]** CSP: не добавлять nonce туда, где есть `'unsafe-inline'` (nonce его выключает).
4. **[сделано]** Межпроцессная блокировка внедрения (lock-файл с pid): после обновления VS Code окна
   больше не переписывают оболочку наперегонки.
5. Проверка прав заранее (пробная запись во временный файл рядом с оболочкой) — предложить
   UAC до сборки плана, а не после ошибки.
6. Несколько бэкапов оболочки с версией VS Code в имени: сейчас бэкап один и после обновления
   VS Code описывает уже не ту сборку.
7. **[сделано]** Сверка файлов и после прямой записи (как после записи с правами администратора).
8. Явная поддержка Insiders, VSCodium и портативной сборки: свой appRoot, product.json, имя папки данных.

## Мост и протокол

9. **[сделано]** RPC только с `Content-Type: application/json` (415 иначе).
10. **[сделано]** Окно предупреждает, если версия протокола хоста не совпала с рантаймом.
11. **[сделано]** Кнопки расширений по хостам: состояние одного окна не стирает кнопки другого,
    клик идёт сначала своему хосту, чужой отвечает `retry`.
12. **[сделано]** Лимит частоты по методам (журнал отдельно от конструктора), а не общий на хост.

    один раз по отпечатку, дальше только изменения.
14. Пульс от окна: хост знает, какие окна живы и какой рантайм в каждом (версия, rev).
